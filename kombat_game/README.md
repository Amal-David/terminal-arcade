# Terminal Kombat

Terminal Kombat is an original large-sprite terminal fighting game for the
arcade. Pick a fighter, win best-of-three rounds against a CPU opponent, manage
health and meter, block incoming hits, and spend meter on specials or finishers.

```bash
python3 -m kombat_game
# or, after install:
terminal-kombat
```

## Controls

| Key | Action |
|---|---|
| Left / A | Move left |
| Right / D | Move right |
| Up / W | Jump |
| Down / S | Crouch |
| J | Punch |
| K | Kick |
| U | Low kick |
| O | Heavy strike |
| H | Sweep |
| ; | Throw |
| L | Block |
| I | Special attack |
| F | Finisher |
| P | Pause |
| R | Restart match |
| Q / Esc | Quit |

## Notes

- Requires Python 3.10+ and a curses-capable terminal around 118x38 or larger.
- The game is dependency-free and uses original fighters, moves, and terminal art.
- Color improves the presentation, but the renderer also supports monochrome terminals.
