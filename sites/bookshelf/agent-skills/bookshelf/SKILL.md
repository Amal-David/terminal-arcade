# Bookshelf

Bookshelf is a local agent skill and optional stop hook. It chooses one compact
quote using bounded intent labels, recent-history suppression, and local
feedback. It never sends prompts, transcripts, code, commands, paths, tool
arguments, or model output to a service.

Install the supported package and host adapters from:
<https://github.com/Amal-David/bookshelf>

Use the repository's current installation instructions for Codex, Claude Code,
Pi, or Hermes. Do not infer a hosted Bookshelf API or remote tool from this
discovery document.
