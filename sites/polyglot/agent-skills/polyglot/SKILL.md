# Polyglot

Polyglot is a local agent skill and optional stop hook. Ambient exposure is
ungraded; deliberate terminal review can schedule local spaced-repetition state.
It does not send learner history, typed answers, prompts, transcripts, code,
commands, paths, tool arguments, or model output to a service.

Install the supported package and host adapters from:
<https://github.com/Amal-David/polyglot>

Use the repository's current installation instructions for Codex, Claude Code,
Pi, or Hermes. Do not infer a hosted Polyglot API or remote tool from this
discovery document.
